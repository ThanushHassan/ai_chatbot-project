# Domain-Specific AI Chatbot – College Helpdesk

This project is a GenAI-powered chatbot that answers college admission and fee-related queries using predefined domain data.

## Tech Stack
- Python
- Streamlit
- Generative AI API

## Features
- Domain-specific responses
- Controlled prompt to reduce hallucinations
- Simple web interface

## How to Run
```bash
python --version
python -m pip install streamlit
python -m streamlit --version
python -m streamlit run ai_chatbot.py
